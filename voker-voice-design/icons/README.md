# Icon system

Use `lucide-react`; no custom font/icon files are included. Keep the icon language thin, geometric, and neutral.

- Navigation: 18–20px, `strokeWidth={1.8}`.
- Metric cards: 20px inside a 32–36px tinted icon container.
- Buttons: 16px; gap 8px to label.
- Status icons must always be accompanied by a text label or badge color.
- Avoid using color alone to communicate resolved/failed states.
